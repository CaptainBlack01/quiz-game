# Quiz Game

A five-question general knowledge quiz built with pure HTML, CSS, and JavaScript.

## Features

- Start, quiz, and results screens
- Four multiple-choice answers per question
- Immediate correct/incorrect feedback with the right answer revealed
- Live score and progress bar
- Tailored result message based on your score
- Restart to play again
- Responsive layout and keyboard-accessible answers
- Respects `prefers-reduced-motion`

## Run

Open `index.html` in a modern browser. No setup required.
